# ANDRÓMEDA 4 — Landing page

Landing page responsive inspirada en el kit de identidad visual de Andrómeda 4.

## Incluye
- Paleta oficial: azul noche `#080F29`, violeta `#8735F5`, turquesa `#00EFF7` y blanco.
- Hero espacial de día, órbitas, planetas, cohete animado y alien caminando.
- Botón de despegue con efecto de sonido sintetizado.
- Control para activar/desactivar sonido (el audio nunca inicia automáticamente).
- Secciones de universo, misión, tripulación y cierre.
- Diseño adaptable a móvil y escritorio, navegación móvil y respeto a `prefers-reduced-motion`.
- Sin frameworks ni dependencias de instalación.

## Personalización
1. Abre `index.html`.
2. Cambia `Integrante 01` a `Integrante 04` por los nombres reales y edita sus descripciones.
3. Ajusta los textos de misión y presentación para que coincidan con el proyecto final.

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en GitHub (por ejemplo `andromeda-4`).
2. Descomprime este ZIP y sube **todo el contenido** de la carpeta (no la carpeta contenedora) a la raíz del repositorio.
3. En GitHub entra a **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`, y guarda.
6. Espera a que GitHub Pages publique el sitio. La dirección será similar a `https://TU-USUARIO.github.io/andromeda-4/`.

> Importante: el sitio funciona como página estática. No requiere Node.js, npm, backend ni claves API. La fuente de Google Fonts usa conexión a internet; si no está disponible, se mostrarán fuentes de respaldo.
